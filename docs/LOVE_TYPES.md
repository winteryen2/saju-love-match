# 연애 케미 타입

| 타입 | 대표 조건 | 의미 |
|---|---|---|
| 💍 결혼상 | 정관·정재가 강함 | 안정적인 배우자성이 강한 장기 연애형 |
| ❤️ 운명상 | 천간합 + 일지 육합 | 강한 인연 요소가 동시에 성립 |
| 🔥 치명상 | 편관 + 일지 충 | 강렬하게 끌리지만 충돌도 큰 관계 |
| 🌸 친구에서 연인 | 비견 + 삼합 | 닮은 결에서 자연스럽게 가까워지는 관계 |
| 🦋 첫사랑상 | 식신 + 천간합 | 편안하고 풋풋한 관계에 특별한 끌림 |
| ✨ 서로 성장형 | 인성 + 오행 보완 | 정서적으로 채워 주고 부족한 기운도 보완 |
| 💕 찰떡 연애상 | 육합·삼합 | 가까워질수록 편안한 시너지가 생김 |
| 💘 끌림형 | 천간합 | 서로를 특별하게 의식하기 쉬움 |
| 🌙 천천히 스며드는 상 | 기타 | 과정 속에서 케미가 형성됨 |

여러 조건이 겹치면 코드에 정의된 우선순위에 따라 대표 타입 하나를 표시합니다.
